# Eii.GithubActions
A repo for CustomActions


there are 2 github actions:

### ReleaseNuGetPackageNet48Net80
This action will create a nuget package for .net framework 4.8 and .net 8.0 projects

You must call it with a:
- runs-on: windows-latest




### ReleaseNuGetPackageNet80
This action will create a nuget package for .net 8.0 projects


You must call it with a:
- runs-on: ubuntu-latest
